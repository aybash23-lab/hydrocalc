# Гидравлический расчёт трубопровода — PWA

Прогрессивное веб-приложение (PWA) для гидравлического расчёта трубопроводов.
Полностью автономное: после установки работает без интернета, расчёт выполняется
локально в браузере. Методика и справочные данные воспроизводят онлайн-калькулятор
prostobuild.by (как и Android-версия этого приложения).

## Возможности

- **Три метода расчёта:**
  - Таблицы Шевелева: 1000i = tк·(q^tв / d^тм), ΔP = 1000i·9.81·L
  - Теоретическая гидравлика: Re, λ (Пуазейль → Блазиус → Альтшуль → квадратичная зона),
    потери на трение R и в местных сопротивлениях
  - СНиП 2.04.02-84 (СП 31.13330): 1000i = (A1000/19.61)·((A0 + C/v)^m / d^(m+1))·v²
- 11 материалов труб, 10 значений шероховатости Кэ, единицы расхода л/с и м³/час
- Живой пересчёт при изменении любого поля
- График ΔP(внутренний диаметр) в логарифмических осях с зелёной зоной
  оптимальной скорости (0,25–1,5 м/с) и красной переходной зоной Re (2320–4000)
- Подбор оптимального диаметра и стандартных условных проходов (подстановка кликом)
- Экспорт: копирование в буфер, системный диалог «Поделиться», текстовый отчёт (.txt)
- Сохранение введённых данных в устройстве (localStorage)
- Офлайн-режим (service worker), установка на телефон и компьютер

## Точность

Расчётное ядро (`calc.js`) сверено с эталонными значениями оригинального
JavaScript-калькулятора prostobuild.by по 13 сценариям (все методы и все ветви
формул): **204 из 204 величин совпадают** (относительное расхождение < 10⁻⁹).

## Локальный запуск

Service worker требует http(s), поэтому просто открывать `index.html` двойным
кликом можно (расчёт заработает), но для установки и офлайна нужен локальный сервер:

```bash
cd HydroCalc_PWA
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Публикация

Приложение — чистая статика, все пути относительные (работает и в корне сайта,
и в подкаталоге). Любой из вариантов:

- **GitHub Pages**: залейте содержимое папки в репозиторий → Settings → Pages
- **Netlify Drop**: перетащите папку на https://app.netlify.com/drop
- **Vercel / Cloudflare Pages / любой хостинг**: укажите папку как статический сайт

Требование: HTTPS (на всех перечисленных сервисах включён автоматически).

## Установка приложения

- **Android (Chrome)**: меню ⋮ → «Установить приложение» (или кнопка «Установить» в шапке)
- **iPhone / iPad (Safari)**: «Поделиться» → «На экран “Домой”»
- **Windows / macOS (Chrome, Edge)**: значок установки в адресной строке

После установки приложение запускается с иконки, без адресной строки браузера,
и работает офлайн.

## Обновление кэша

При изменении файлов приложения увеличьте версию кэша `CACHE` в начале `sw.js`
(например, `hydrocalc-v1.0.1`) — браузеры получат новую версию при следующем визите.

## Структура файлов

```
HydroCalc_PWA/
├── index.html            — единственная страница приложения
├── app.css               — светлая инженерная тема (та же палитра, что в Android-версии)
├── calc.js               — расчётное ядро (формулы 1:1 с prostobuild.by)
├── chart.js              — график ΔP(D) на canvas, логарифмические оси
├── app.js                — логика интерфейса, экспорт, PWA-поведение
├── manifest.webmanifest  — манифест PWA (имя, иконки, тема)
├── sw.js                 — service worker (офлайн-кэш)
└── icons/                — иконки (обычные, maskable, apple-touch-icon)
```
